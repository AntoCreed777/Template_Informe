# Contribuciones

Si quieres mejorar el template:

1. Haz un fork.
2. Crea una rama nueva.
3. Realiza tus cambios.
4. Verifica que compile.
5. Envía un pull request.

## Ideas de mejora

- nuevos ejemplos de tablas, figuras, código u otras cosas.
- mejor documentación
- más estilos para portada y secciones
- limpieza de paquetes innecesarios
- compatibilidad con más flujos de compilación
