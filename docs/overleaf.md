# Overleaf

Overleaf es un editor y compilador de LaTeX en la web. Es útil si no usas Linux, si quieres trabajar desde otro sistema operativo o si prefieres evitar una instalación local.

## Cómo usar este template allí

1. Crea un proyecto nuevo en Overleaf.
2. Copia el contenido de `src/` dentro del proyecto.
3. Mantén la estructura de carpetas para que funcionen `\input{...}` y `\include{...}`.
4. Sube también las imágenes que uses en `src/figures/`.
5. Selecciona `main.tex` como archivo principal.

## Por qué es una alternativa válida

- no depende de Linux ni de herramientas locales
- permite compartir el informe fácilmente
- funciona desde cualquier navegador
- mantiene el mismo flujo de archivos del template
