\subsubsection{Pseudocódigo}

Para pseudocódigo, puedes usar el paquete \texttt{algorithm2e}:

\begin{algorithm}[H]
    \SetAlgoLined
    \KwResult{Suma de dos números}
    \KwData{a, b}
    \Begin{
        resultado $\leftarrow$ a + b\\
        Imprimir resultado
    }
    \caption{Algoritmo de suma}
    \label{alg:suma}
\end{algorithm}
